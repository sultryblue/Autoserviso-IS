Europe_Vilnius is an unmodified TZif file for Europe/Vilnius.
Source: system IANA tzdata 2025b, /usr/share/zoneinfo/Europe/Vilnius.
The tzdata input declares its data to be in the public domain.
Reference: https://www.iana.org/time-zones
Used only when the system and the Python tzdata package have no Europe/Vilnius data.
